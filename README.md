# orai-language-community
おらいのLanguageコミュニティ：やめても、誰でもForkして始められる会話の場

シンプルでフォーク可能な、言語コミュニティ運用ドキュメントのテンプレートです（GitHub Pagesで公開）。英語に限らず、新しい言語のコミュニティを作りたいと思った人が、このテンプレートを使って手軽に始められるようにします。テンプレートをフォークすれば、英語だけでなくインドネシア語などの他言語や、学生向け、社会人向け、読書好き、ゲーム好きといったコミュニティのページを作ることができます。

私自身、市内の英会話コミュニティに1、2年ほど参加するなかで、「もう少し頻度を増やせないか」「平日の夜にできないか」と感じ、その課題を解決するために実験的な英会話コミュニティを立ち上げました。このような身近で小さな課題は、自分で場や仕組みを作ることで解決できる場合があります。そうした最初の一歩を手助けし、その後も使われ続ける「外部足場(external scaffolding)」として機能することを目指しています。

まずは現在のコミュニティ運用ドキュメントをテンプレートとして整え、私自身が運用します。新しく言語コミュニティを始めたい人には、ページをフォークしてもらいます。GitHubの使い方は私がサポートします。フォーク先での改善は、プルリクエストとして受け取ることもできます。いつか私に何かあって英会話コミュニティを続けられなくなっても、私を含めた参加者は、フォーク先のコミュニティに参加できます。
